# ADR 0005: The name Paperline

## Status

Accepted

## Context

The repository and the on-screen title needed one English name. The author asked to choose it.

## Decision

Rafał selected **Paperline**. The other options were Inkling, Quietmark, Inkcard, Hatchlet, Stillgrid, Softgrid, and Linelet.

## Consequences

The GitHub repository, Wrangler script name, and masthead all use Paperline.
